三步开始编辑

  1. 打开一个图表。通过“导入 → 粘贴 WaveJSON”粘贴已有时序，或选择“导入示例”。首次尝试可复制下方的练习数据。
  2. 选工具，再操作。用 0／1 等笔刷落状态，向右拖动延续；调整边界前改选“选择”并关闭自动连续模式。毛刺笔刷只用于同电平尖刺切换。
  3. 保存可编辑原稿。完成后下载 JSON；需要图片时再导出 SVG 或 PNG。重要编辑可随时 Ctrl＋Z 撤销。

最常用的绘制方式

选择 1 笔刷，在目标格按下并向右拖，后续格写成延续符；再选择 0 笔刷，点出有效区间的结束位置。普通滚轮也能上下调整状态。

01 / VIEW

以鼠标位置为中心缩放时间轴

鼠标放在编辑网格内，按住 Ctrl 滚动滚轮。放大时看清局部，缩小时查看整段时序；鼠标对应的时间点尽量保持原位。

  • 缩放范围为 25%～300%，点击网格工具栏的百分比恢复 100%。
  • 行高和文字字号保持可读；上下刻度自动减少显示，避免数字重叠。空间不足的数据标签会省略显示，适用时可悬停查看全文。
  • 只改变编辑网格的时间轴显示，不修改 WaveJSON 的 hscale，也不改变右侧实时预览的缩放。

照着做

  1. 鼠标放在编辑网格的目标时间附近。
  2. 按住 Ctrl 上滚放大、下滚缩小。
  3. 点击编辑工具栏的百分比回到 100%。
02 / TIMING

拖动边界，调整时序

先选中“选择”工具并关闭自动连续模式。鼠标靠近电平翻转或总线分段边界，出现左右拖动光标后，按住左键拖动。移动按本信号的整拍吸附。

普通拖动：调整局部

移动当前边界。连续单拍总线或紧邻的单拍翻转没有空隙时，顺延发生碰撞的相邻内容，保留数据顺序、标签和节点；遇到空闲位置即停止推动。

Alt＋拖动：后续一起延迟

按下鼠标时按住 Alt，再向右拖动。后续所有内容一起移动，彼此间距保持不变；其他信号不动。拖回起点恢复原位置，不会向左覆盖此前内容。

支持 0...1...、00001111 等表示方式，也识别电平、未知态、高阻态与总线之间的相应边界。鼠标、触摸和触控笔共用边界拖动逻辑。

真实节点、间隙或其他标记仍会受到保护。若出现禁止光标，请查看边界提示。p/n 自动生成的时钟内部半拍边沿，暂不支持单独拖动。

照着做

  1. 选择“选择”工具，关闭自动连续模式。
  2. 靠近真实翻转处，确认出现左右拖动光标，再按下左键。
  3. 普通拖动只调整局部；要让全部后续一起延迟，在按下鼠标前按住 Alt。
  4. 拖错时先按 Esc 取消；松开后可用 Ctrl＋Z 撤销。

连续单拍总线怎么调？

像 x...222=x... 这样的数据没有空闲拍，也可以直接拖边界。发生碰撞时只推动必要的数据块，已有数据顺序和标签不丢失。

03 / PRECISION

Alt＋滚轮，只改当前一格

普通滚轮改变状态后，后面的 . 会继续继承它。按住 Alt 再滚动，会在下一格补回原状态，避免微调传播到整段。

普通滚轮：影响后续延续

例如把中间一格从低电平上滚成高电平：

0.... → 0.1..

对应逐拍电平：00000 → 00111。

Alt＋滚轮：插入单拍变化

同样修改中间一格，下一格恢复低电平：

0.... → 0.10.

对应逐拍电平：00000 → 00100。

总线标签会在恢复原状态时保留。自动连续模式下，滚轮仍只作用于当前锁定格，不会自动推进。

照着做

  1. 悬停在需要微调的格子，上滚提高、下滚降低状态。
  2. 希望只改一格时，滚动前按住 Alt。
  3. 观察下一格是否恢复原值；不要把 Ctrl 缩放与 Alt 单格微调混淆。
04 / ERASE OR DELETE

清除与删拍，是两种操作

WaveDrom 没有通用的“中间空白一拍”字符。这里将清除内容明确设为高阻态 z，不再把它当作“变成延续格”。

右键：当前格变为高阻态

清除第 2 格（从 0 起），总长度不变，下一格恢复原低电平。

原来：0...1...
之后：0.z01...
Alt＋右键：删除这一拍

同样操作第 2 格，删除一个延续格，后面的上升沿提前一拍。

原来：0...1...
之后：0..1...
  • “清除本格”按钮和清除工具也采用高阻态语义。
  • Alt＋右键只缩短当前信号，其他信号与全局刻度不变。
  • 删除或清除当前节点时，会清理引用该节点的连线；后续仍存在的节点及其连线关系会保留。
  • 清除末尾格仍保留长度；工具栏的末尾减拍按钮则真正缩短波形。

照着做

  1. 需要保留拍位时，右键当前格，将它设为高阻态 z。
  2. 需要缩短这条信号时，按 Alt＋右键删除当前拍。
  3. 对照其他信号和全局刻度，确认只有本信号后续前移。
05 / CONNECTIONS

连线按“形状＋方向”选择

不必从一长串符号中辨认样式。现在分别选择路径形状和箭头方向，旁边实时显示实际路径预览；全局连线面板和节点连线弹窗使用同一套控件。

路径可用方向
直线、平滑曲线、直转曲无箭头／终点箭头／双向箭头
曲转直无箭头／终点箭头
先横后竖、横→竖→横无箭头／终点箭头／双向箭头
先竖后横无箭头／终点箭头
范围标记两端短杠

覆盖内置 WaveDrom 原生支持的 20 种组合，不支持的方向会禁用。切换形状时尽量保留原方向，不支持时使用可用方向。保存仍是标准 edge 语法。

照着做

  1. 在两个目标格中放置节点标记，再打开连线面板。
  2. 选择起点、终点与路径形状，再选择箭头方向。
  3. 用旁边的小预览确认走线，输入标注，最后查看波形中的实际连线。
06 / GLITCH BRUSH

毛刺笔刷：同电平显式字符与延续符切换

沿用“一键去毛刺”的同电平归一化规则，但只处理点选或涂到的格子。例如，WaveDrom 会在 1111／0000 的重复显式字符处画三角尖刺；1...／0... 则保持平线。编辑网格现在也显示这些官方样式的尖刺。

点击预览底栏的“毛刺笔刷”，或在笔刷栏选择“毛刺”，然后在编辑网格上操作。

点重复的显式字符：去除

只将当前格改为延续符，不改变该段的高低电平、长度或其他毛刺。

1111 → 11.1

连续涂过后续三格，可得到 1...。

再点延续格：添加／恢复

将延续符恢复成该段的同电平显式字符；低电平采用对应规则。

1... → 1.1.

原来是 h/H/l/L 的格子，在当前编辑过程中再次点选会恢复原字符样式。

  • 拖涂根据第一个有效格决定本次“去除”还是“添加”；一次拖涂中每格只切换一次。
  • 段首、正常上升沿和下降沿不作去毛刺处理，010/101 的真实单拍脉冲也不被当作毛刺删除。
  • 不改变时间长度，节点、连线和其他信号保持原样；不会跨越时钟、总线、未知态、高阻态或间隙。
  • 编辑区的 1m1／0m0 半高度三角尖刺与 WaveDrom 官方皮肤对应；h/H/l/L 保留其原有垂直沿与箭头形态。
  • 整次拖涂可以一次撤销；按 Esc、取消触摸或失去窗口焦点可取消当前笔刷操作。
选择毛刺笔刷时会退出自动连续模式，并关闭自动去毛刺，避免全自动规则覆盖手动保留的毛刺。原有“一键去毛刺”仍作用于全图；只想修改局部时请使用笔刷。

照着做

  1. 点击预览底栏或笔刷栏中的“毛刺”入口。
  2. 点重复的 1／0 去掉该处尖刺；再点延续格可恢复。
  3. 需要处理一段时拖涂过去；起点决定整笔是“去除”还是“添加”。
SAVE YOUR WORK

保存、导出与继续编辑

你要做什么推荐操作
以后继续改时序“导出 → 下载 JSON”，下次通过“导入 → 打开文件”恢复。
放进文档、演示或网页下载 WaveDrom SVG（矢量）或 PNG；需要编辑网格的现代配色时，选择“编辑区 SVG／PNG”。
交给其他人继续编辑优先发送 JSON 原稿，也可以发送编辑器导出的、内嵌 WaveJSON 的 SVG／PNG。
在其他绘图工具里修改形状导出 draw.io 或 Excalidraw；这些是形状快照，不能还原成可编辑的 WaveJSON。
浏览器自动保存方便继续工作，但重要图表仍建议下载 JSON 文件留档。演示中的 Ctrl＋Z 只撤销当前图表操作，不是浏览器的“返回”。
TROUBLESHOOTING

遇到问题，先检查这里

为什么拖不动边沿，或者出现禁止光标？

先确认选的是“选择”工具、自动连续模式已关闭，并且鼠标靠近真实边界。独立节点、间隙或受保护标记可能限制移动；查看悬停提示。p/n 自动生成的半拍边沿暂不支持单独拖动。

毛刺为什么不是 010／101 脉冲？

本笔刷沿用一键去毛刺的同电平规则：1111 → 1...、0000 → 0...。010/101 是真实电平变化，不会被这个笔刷删除。

清除后为什么显示 z，而不是空白？

WaveDrom 没有通用的“中间空白一拍”字符。右键明确将当前格设为高阻态 z；要让这拍消失、后续前移，请使用 Alt＋右键。

Alt 单格修改为什么在间隙旁没有生效？

下一格若是 |，恢复原状态会与保留间隙冲突，因此程序会提示并保护原内容。先调整间隙位置或使用普通状态笔刷。

动图看不清，或者想慢慢对照操作？

点击“单独查看／保存动图”打开原尺寸 GIF。看完一组点击“停止播放”，再按本节的步骤在编辑器中操作。页面默认使用静态封面，避免多个动画同时干扰阅读。

BEFORE YOU START

几个容易混淆的地方

  • . 延续上一状态；x 是未知态；z 是高阻态；| 是间隙标记，它们都不是通用空白格。
  • 单格修改或清除时，如果下一格是间隙标记 |，会提示并保护原内容，避免为了恢复状态而丢失间隙。零宽子周期标记也受到保护。
  • 普通拖动和 Alt＋拖动只在选择工具、非自动连续模式下启动，笔刷涂抹保留原来的行为。
  • 拖动期间按 Esc 取消；完成后用 Ctrl＋Z 撤销，Ctrl＋Y 重做。Mac 可使用对应的 Command 撤销快捷键。
